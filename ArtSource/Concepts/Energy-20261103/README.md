# Phố Việt — Mẫu icon năng lượng chờ duyệt

Chỉ là bản tham khảo dựng bằng Blender MCP, chưa nhập Unity/chưa thay game/web.

- A: Khối xanh ngọc bo cạnh, hông xanh đậm, gần ảnh tham khảo nhất.
- B: Tia sét xanh góc cạnh, mặt chia mảng như pha lê.
- C: Tia sét trong vòng năng lượng sáng, dễ nhận diện.

Xem `energy-abc-board.png`; nguồn thật `PhoViet_Energy_Approval.blend`; script dựng `create_energy_concepts.py`; trạng thái `approval.json` vẫn false. Đế/nhãn/nền/đèn studio chỉ phục vụ xem mẫu. Chưa tối ưu LOD hay xuất asset gameplay.

Chờ người dùng chọn A/B/C hoặc yêu cầu chỉnh. Khi được duyệt mới triển khai các luật năng lượng đã ghi trong approval.json; xác nhận thêm cách thoát bay/hết năng lượng/hướng nhào lộn/phím desktop nếu chưa được chốt.
